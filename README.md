# API Movie

API básica que simula um catálogo de filmes com endpoints de listagem e detalhes.

---

## Como executar o projeto

Instalar dependências:
npm install

Rodar no modo de desenvolvimento:
npm run dev

---

## Decisões de arquitetura

Estrutura MVC simples (routes, controllers, data).​

Dados mockados em JSON para acelerar desenvolvimento do front.​

CORS habilitado para consumo por apps como PFlix.

---

## Tecnologias

Node.js/Express, JSON mocks, CORS.​
